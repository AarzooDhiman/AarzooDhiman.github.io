# Photos for the journey globe and profile

Drop photos in this folder with these exact names. Claude Code will resize them to WebP (1600 px and 800 px wide) and move them into `assets/img/`.
Landscape (about 3:2), at least 1600 px wide. Your own photos are best. If a photo is someone else's, add a line to `credits.txt`: `filename | title | author | licence | source URL`.

| File name | What | Used for |
|---|---|---|
| `headshot.jpg` | Professional portrait, plain background, shoulders up (portrait 4:5 is fine) | Profile intro and the link-preview image |
| `kurukshetra-university.jpg` | Kurukshetra University campus | Globe stop 1: BTech 2010–2014 |
| `nit-kurukshetra.jpg` | NIT Kurukshetra campus or main building | Globe stop 2: MTech 2014–2016 |
| `iit-roorkee.jpg` | IIT Roorkee main building | Globe stop 3: PhD 2017–2022 |
| `kdd-2018-london.jpg` | You with the epiDAMIK poster at KDD 2018, London (if you have one) | Globe stop 4: first talk in London |
| `ucl.jpg` | UCL main building / portico, or your department | Globe stop 5: postdoc 2021–2023 |
| `university-of-hull.jpg` | University of Hull campus (e.g. the Venn Building) | Globe stop 6: Teaching Fellow 2023– |

Optional, only if real and allowed:
- `jetson-device.jpg`: the edge device on your desk (no patient information or screens with data)
- `teaching.jpg` / `hackathon.jpg`: only with consent from anyone visible
