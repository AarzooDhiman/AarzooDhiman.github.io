# aarzoodhiman.github.io: project notes for Claude

Everything needed to continue, or to rebuild from scratch, Dr Aarzoo Dhiman's CV site. Nothing private is in this file (no phone number, no contact details beyond what the site shows). The private fact source is `site-source/CV_FACTS.md`, kept out of git.

## 1. Working rules (the owner's standing preferences)
- Do not commit or push unless asked. When asked to push, stage explicitly and keep private files out (see section 11).
- Make the simplest change that works. Verify every change by looking at Playwright screenshots at 390x844 and 1440x900 before moving on. Also check: no console errors, no horizontal scroll, Lighthouse mobile Performance 90 or more and Accessibility 100 on every page, text contrast at least 4.5:1, tap targets at least 44 px.
- Facts only from `site-source/CV_FACTS.md` and the existing site text. Never invent numbers, dates, titles, outcomes, quotes, testimonials or logos. Keep "Illustration" labels on visuals that are not real data (and "An illustration driven by the paper's estimates. It is not patient data." on the simulator). When something new or moved appears, update `site-source/FACT_AUDIT.md` (every number and date with its source line).
- No phone number anywhere on the site. No stock or fake images: use typographic placeholder cards until real photos exist. When photos or files are needed, stop and ask the owner.
- Do not edit `classic.html` (old site, build output of `site-source/v1-classic/src.html`).
- Dates: facts come from CV_FACTS.md; the owner's own briefs may add details (flagged "Confirm" in FACT_AUDIT.md).

## 2. Stack and skills used
- Plain static site, no framework, no bundler for pages. GitHub Pages serves the repo root. Pages are hand-edited HTML.
- Libraries (copied from npm by `site-source/build.py` into `assets/js/vendor/`): GSAP 3.13.0 + ScrollTrigger (pinning and scrubbing), Lenis 1.3.11 (smooth scroll, not on touch). Fonts (woff2 in `assets/fonts/`, preloaded): Bricolage Grotesque variable (display) and Instrument Sans variable (text).
- Techniques: canvas 2D scenes through one shared render loop (IntersectionObserver start/stop); scroll-scrubbed pinned stories; morphing dot formations; an orthographic dotted globe with a camera (zoom, pan, fly) and level-of-detail; a small TopoJSON reader in JS; cross-document View Transitions (`@view-transition{navigation:auto}`); FLIP animation with the Web Animations API; native scroll-snap swipe rows; CSS grid-rows accordion; `prefers-reduced-motion` plus a user motion switch; masked line reveals for headings.
- Tools: Playwright (screenshots, flows, frame timing; installed in a scratch folder, not in the repo), Lighthouse CLI (run against a gzip server because GitHub Pages gzips), mapshaper (`npx mapshaper`) and Natural Earth data for maps, sharp (`site-source/make-images.mjs`) for photos, node + d3-geo + topojson-client + world-atlas (`site-source/v2-signal/make-globe.mjs`) for globe dot data, Python 3 for small scripts. No Claude Skills were needed; all work was done with the standard file, shell and browser tools.
- Environment gotchas: the repo sits in OneDrive; `git add` can fail with "mmap failed: Operation timed out" on a file that was just written. Fix: delete and regenerate that file, then add it. macOS has no `timeout` command and `sed -i` needs `''`. The owner may already run a server on port 8000, so test on another port (8010). Lighthouse performance reads about 89 without gzip and 96 to 98 with it.

- Theme: dark by default, light on request. A moon/sun button in the ribbon (`#themeBtn`) sets `data-theme` on `<html>` and stores `ad-theme` in localStorage (the pre-paint script in every page head applies it). Channels are space-separated (`--paper-rgb:241 238 230`, used as `rgb(var(--paper-rgb) / .12)`); commas break `rgb()` with a slash. Canvas code must read colours from `AD.TH` (`TH.paper`, `TH.signal`, `TH.bg2`, `TH.bg3`, `TH.rgba(a)`), never hard-code hex; toggling calls `kick()` so scenes redraw, and reloads in reduced-motion mode.
- Motion: `<html class="js">` set before paint; `html.static` when reduced motion or the user switched motion off (`localStorage ad-motion`). All animation CSS is under `html.js:not(.static)`. Reveals: `[data-rise]` (fade and rise), `[data-lines]` headings split into masked lines (plain text only, no links inside).
- Ribbon: fixed bar with name "Dr Aarzoo Dhiman" (home link), nav pills Profile · Research · Funding & talks · Contact (active page filled pill with `aria-current="page"`; Contact is `#contact` on the current page), and a Download CV button (`Aarzoo_Dhiman_CV.pdf`, repo root). ## 9. Scroll stories (`story.js`)
- `scrollStory({stage, canvas, steps, prog, makeRenderer})`: one pinned stage (`.story__stage`, height `100svh - bar`), one canvas, one `.story__step` visible at a time, progress counter "k of 7", `ScrollTrigger` pin with end `+= innerHeight * (steps-1) * 0.8`, scrub, `cur` eased toward target (0.14 per frame), step number counted up when shown, no-GSAP fallback (IntersectionObserver). Phones keep the pin (canvas on top, text below). Reduced motion / no JS: steps become a plain ordered list, each with its own still canvas (`makeRenderer(w, h, true)`); the main canvas is hidden. `formations(n, S)` holds S formations of n dots (`set(s,i,x,y,alpha,size,color)`, size is a radius above 3.2) and morphs between neighbours with a per-dot delay; scrubbing back plays it backwards.
